# 📁 reports/

This folder contains reports generated by the AI agent (GitHub Copilot CLI) after each session of changes to the project.

## Instructions for the AI Agent

After every session where changes are made to the project, you **must** create a new report in this folder following the rules below:

### 1. File naming
```
YYYY-MM-DD_DESCRIPTIVE_NAME.md
```
Use the date of the session and a short name describing the changes made (e.g. `2026-03-01_TESTING_REPORT.md`).

### 2. Required report structure

```markdown
# Report Title — Project Name

**Date:** DD/MM/YYYY
**File:** `reports/YYYY-MM-DD_NAME.md`
**Tool:** GitHub Copilot CLI

---

## Summary
Table with totals: files created, files modified, bugs fixed, tests added.

## Sections per change type
Detail every file created, modified, or deleted.
For each change: what it does, why it was done, what problem it solves.

## Bugs Fixed
For each bug: file, before/after diff, root cause, effect if not fixed.

## Final Result
Test run output and pass/fail counts.

## Files Changed
Full table: file path | action (Created / Modified / Fixed) 
```

### 3. Update this index
After creating the report file, add a row to the table below.

### 4. Language
**All reports must be written in English.**
